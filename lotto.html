로또 번호 추첨기

1부터 45까지의 숫자 중 중복 없이 6개의 번호를 무작위로 추첨하는 게임입니다.

← 메인으로

추첨 버튼을 누르면 여러 세트의 로또 번호가 자동으로 생성됩니다.

아직 생성되지 않았습니다.

생성 기록

• 기록은 브라우저 로컬스토리지에 저장됩니다.
• “기록 전체 삭제”는 되돌릴 수 없습니다.
• ESC 메인

게임 가이드

추첨 방식과 사용 팁을 정리했습니다.

추첨 방식
  • 1~45 사이의 숫자에서 중복 없이 6개를 무작위로 선택합니다.
  • 추첨 결과는 참고용이며 당첨을 보장하지 않습니다.
  • 기록은 로컬스토리지에 저장됩니다.
사용 팁
  • 여러 조합을 비교해 다양성을 높여보세요.
  • 동일 숫자 패턴의 반복 사용은 피하는 것이 좋습니다.
