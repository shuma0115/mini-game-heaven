# Mini Games (멀티페이지)

## 파일 구성
- index.html : 메인 페이지(게임 선택)
- rps.html / rps.js : 가위바위보
- omok.html / omok.js : 오목
- lotto.html / lotto.js : 로또 추첨기
- style.css : 공용 스타일
- shared.js : 테마/효과음/오디오 엔진 공용

## 실행 방법
1) 이 폴더를 그대로 두고 `index.html`을 더블클릭(로컬 실행)
2) 크롬/엣지 권장

> 일부 브라우저는 로컬 파일에서 오디오가 첫 클릭 전까지 재생이 제한될 수 있습니다.
